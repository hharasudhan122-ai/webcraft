💡 Offline LAN vs. Cloud Link (Render / Vercel):
• When on Render: The link loads over the Internet. If you lose internet connection, the Render webpage cannot open.
• True Offline LAN (0% Internet): One player simply downloads/clones the GitHub repo on their laptop, runs npm install && npm start, and hosts locally. Anyone connected to the same Wi-Fi or phone hotspot can then open http://<HOST_IP>:3000 with no active internet required!
